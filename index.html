Cara Setup Script Database Spreadsheet:
  1. Buka Google Sheets baru & Klik menu Extensions > Apps Script.
  2. Hapus semua isi script & Paste kode di bawah ini.
  3. Klik Deploy > New deployment, pilih Type Web App.

  5. Copy URL Web App lalu paste ke kolom URL di atas.
